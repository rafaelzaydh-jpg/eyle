# Eyle 2.7.4 Rev4.11.4.1 — Write-intent gate hotfix

Rev4.11.4.1 fixes a regression where a direct editing request such as `Extraia o html para templates/amor.html` could be treated as a factual conclusion. The factual-response validator then rejected the model's unsupported completion claim with `FINAL_CLAIM_REQUIRES_EVIDENCE`, instead of requiring an actual write proposal.

The runtime now detects conservative direct write intent before final validation. When editing is available, prose-only completion is rejected with `FINAL_WRITE_ACTION_REQUIRED`; the model receives explicit feedback to read the necessary files and produce one dry-run transaction for user confirmation. Questions about how to edit and analysis-only requests are not classified as write commands.

Validation: 113 passed, 1 optional Flask test skipped. The exact reported HTML-extraction scenario is covered by a regression test.

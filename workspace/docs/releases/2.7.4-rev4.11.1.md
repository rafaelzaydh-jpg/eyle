# Eyle 2.7.4 Rev4.11.1 — Complete cleanup

Rev4.11.1 keeps the Rev4.11 architecture and removes the remaining inactive compatibility code:

```text
Interface → runtime service → AgentSession → LLM ↔ tools/memory → response
```

Removed in this revision:

- model-response cache and its configuration, because every active LLM call is an AgentSession decision and must be fresh;
- legacy `memory/projeto.json` workspace fallback;
- duplicated result fields and the obsolete `completion_gate` envelope;
- core-generated confirmation IDs and duplicated pending metadata;
- unused text persistence, telemetry reset, imports, constants, and compatibility aliases.

The runtime still owns queueing, cancellation, confirmation, atomic writes, tests, rollback, reread, deadlines, token accounting, progress, and telemetry.

Validation: 84 tests passed; one optional Flask interface test was skipped because Flask is unavailable in the packaging environment.

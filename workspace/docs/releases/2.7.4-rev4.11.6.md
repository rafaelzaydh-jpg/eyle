# Eyle 2.7.4 Rev4.11.6 — Claim-to-answer alignment

Rev4.11.6 fixes `FINAL_CLAIM_NOT_IN_ANSWER` failures caused by harmless wording differences between the natural answer and its internal evidence ledger.

## Changes

- The compact agent prompt now explicitly requires every `claims[].text` to be copied verbatim from one sentence in `final.answer`.
- The runtime attempts one conservative deterministic alignment before rejecting a claim.
- A successful alignment stores the exact visible answer sentence as the claim text and retains the model's original wording plus method and score for diagnostics.
- Alignment preserves polarity and requires numeric, file-path, and code-identifier terms to remain present.
- Changed frameworks, reversed claims, or materially different statements are rejected normally.
- Failed alignment receives precise feedback telling the model to copy the sentence verbatim, avoiding repeated generic retries.
- Prompt size remains about 406 conservative tokens.

Validation: 128 passed, 1 optional Flask test skipped because Flask is not installed in the packaging environment.

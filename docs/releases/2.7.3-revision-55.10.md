# Eyle 2.7.3 — Revision 55.10

## Expandable operational work summary

Revision 55.10 adds a compact, expandable work summary to every completed question job. The collapsed row shows only the elapsed time, for example:

```text
Trabalho concluído em 2m04s
```

When expanded, the browser displays four structured stages:

1. **Entendimento** — the objective received from the user.
2. **Leitura** — files, line ranges, and whether the read was complete.
3. **Análise** — mode, tools used, and evidence IDs collected.
4. **Conclusão** — final status, fallback usage, validation result, and limitations.

The summary is generated from the Engine result and fresh evidence metadata. It does not expose prompts, chain-of-thought, raw tool output, hidden model fields, or source-code contents.

## Implementation

- Added `engine/work_summary.py` as a deterministic adapter from job/result data to a small public schema.
- Persisted the summary inside the job progress record before completion.
- Added safe nested sanitization in `GET /jobs/<id>`.
- Added total-line and full-read metadata to Agent evidence.
- Added equivalent read metadata to the small-project full-code fallback.
- Added a native HTML `<details>` block in the conversation UI.
- Preserved completed summaries in the current browser session while old failed jobs remain discarded.

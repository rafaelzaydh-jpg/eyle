# Eyle 2.7.3 — Revision 55.14

## Unified Response Recovery Pipeline

Revision 55.14 replaces the accumulated response/grounding hotfix chain with one explicit pipeline:

```text
read project
→ generate analysis
→ utility gate
→ typed grounding
→ selective repair
→ final utility gate
→ publish
```

## Main changes

- Normalizes OpenAI-compatible, Ollama-style, streaming, partial-JSON, reasoning-only, and plain-text server responses at one boundary.
- Returns `EMPTY_MODEL_RESPONSE` when no usable model content exists.
- Rejects evidence receipts and file/range listings as final conclusions.
- Recovers in layers, ending with deterministic evidence-only analysis before returning `failed`.
- Never invokes grounding to rescue an empty response.
- Uses one `EvidenceRegistry` across tools, grounding, persistence, and UI.
- Preserves valid typed recommendations and reasoning while removing only rejected factual claims.
- Reopens legacy persisted false-success results when they fail the new utility gate.

## Status contract

- recoverable error → retry internally
- useless response → recover internally
- invalid grounding → selectively repair
- real technical failure → `failed`
- genuine human decision → `needs_user`
- useful validated response → `success`

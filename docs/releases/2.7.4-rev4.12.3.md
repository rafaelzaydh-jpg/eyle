# 2.7.4 Rev4.12.3 — Tool contracts and LLM-led investigation hardening

Rev4.12.3 is a foundation release built directly on Rev4.12.2. It intentionally does **not** add the planned self-debug trace tool yet; it first makes the existing agent/tool/runtime relationship reliable enough for that next step.

## What changed

- Model-visible tool definitions are now compact semantic contracts with `purpose`, `inputs`, `returns`, `does_not`, `side_effects`, and configured `limits`.
- Tool-specific routing hints were removed. A tool describes only its own observation/action boundary; the LLM decides which combination is useful.
- Workspace routing now keeps only obvious chat/calculator/self-info as cheap fast paths. Other workspace requests receive investigation capability without needing a keyword such as “analyze”.
- The write-intent gate remains only a conservative prose-completion guard. Presentation language such as “separate risks from bugs” no longer arms write phases, while clear mutation commands still do.
- If wording is ambiguous, the general analysis flow exposes supervised dry-run patch tools after real evidence has been collected. Dry-runs still cannot write and all real writes still require confirmation.
- `run_tests` closes tools only when runtime state shows it was the sole project observation and no multi-step plan remains. A compound analysis can continue after tests or `TEST_RUNNER_UNAVAILABLE`.
- The fixed agent contract forbids invented project-specific implementation facts but explicitly preserves free hypotheses, opinions, tradeoffs and recommendations when clearly framed.
- Public history shows each tool name as a visible line and can recover the name from older summarized result records.
- Generic context cropping now reaches a stable floor for already-cropped strings instead of repeatedly appending the crop suffix.
- `pytest==8.2.2` remains a runtime dependency and is covered by a Rev4.12.3 regression.

## Validation

- 171 deterministic tests passed.
- 1 optional Flask-interface test skipped because Flask is absent from the packaging environment.
- Fixed agent prompt remains under the 450-token fallback target (448 estimated at 3 chars/token).

## Intentionally deferred

The next implementation may add generic execution tracing/self-debug inspection so Eyle can run controlled tasks, inspect observable execution events, inspect the responsible source, and test a hypothesis again. Rev4.12.3 does not add that capability yet.

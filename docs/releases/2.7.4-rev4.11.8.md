# Eyle 2.7.4 Rev4.11.8 — Project intelligence tools

Rev4.11.8 keeps the Rev4.11.7 phase-controlled agent and adds deterministic tools so measurements come from executable code instead of LLM guesses.

## Added

- `calculate`: safe deterministic arithmetic with explicit exact/approximate status.
- `project_stats`: safe text file, directory, line, character, byte, extension and language measurements.
- `count_tokens`: measured project text converted through the configured fallback ratio; reports `exact: false` without an exact tokenizer.
- `inspect_project`: objective entrypoint, local-import, route, test, CI, framework, manifest and configuration signals. It never labels files important.
- `agent_info`: runtime identity and executable capability registry for self/tool questions.

## Behavior fixes

- General/self conversation no longer fails merely because the LLM emitted an optional structured claim without project evidence.
- Greetings remain tool-free; calculator/self tools are exposed only when the request gives a concrete reason.
- Deterministic project-observation results become citable evidence for project answers.

## Validation

- 145 tests passed.
- 1 optional Flask interface test skipped because Flask was unavailable in the packaging environment.

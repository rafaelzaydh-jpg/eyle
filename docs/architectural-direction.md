# ECC Evolution Rule

Before adding anything to Core, ask:

1. Does it require interpretation? If yes, Main decides.
2. Is it an objective fact or enforceable physical constraint? If yes, Runtime/provider owns it.
3. Can Main already decide it from observations? If yes, do not add a router/state machine.

The architecture should grow in operations, safety and observability without growing another semantic coordinator around the LLM.
